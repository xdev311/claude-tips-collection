## Overview

This thread explains how most users only use about 10% of Claude's capabilities. It provides a complete setup guide to turn Claude into a true thinking partner that remembers you, understands your style, and works efficiently.

The key recommendation is to use **Projects** instead of regular chats for persistent context.

## 1. Start Here – Proper Setup

### Create a Project (not a chat)
Every new chat starts with zero memory. Projects keep context across conversations.

**How to create**:
1. In Claude, click **Projects** in the sidebar
2. Create a new Project (e.g. “Personal”, “Work”, “Writing”, etc.)
3. Do all future work inside this Project

### Tell Claude who you are
Fill out a detailed personal background in the Project’s **Knowledge** section. Include:
- Your name
- Work / profession
- Goals
- Communication preferences
- Writing style examples
- Anything important about how you think and work

The more honest and detailed, the better Claude performs.

### Generate Custom Instructions
After filling the background, ask Claude to generate strong **Custom Instructions** based on it. Then paste those instructions into the Project’s **Instructions** section.

This becomes Claude’s default behavior for the entire Project.

## 2. Mindset Shift

**Claude is not a search engine**

Stop using it like Google. It excels at reasoning, synthesizing, critiquing, and building ideas.

**Bad prompt**: “What is prompt caching?”
**Good prompt**: “I’m building a workflow that calls Claude 20 times per session. Explain how prompt caching works and whether it will meaningfully reduce costs in my case.”

**Always ask Claude to ask you questions first** before starting complex tasks. This removes assumptions.

## 3. Advanced Techniques Most Users Miss

- **Style Cloning**: Feed Claude 3–5 samples of your own writing and ask it to deeply analyze your voice, tone, sentence structure, and quirks. Then have it write in your exact style.

- **Sparring Partner Mode**: Instead of just asking for feedback, ask Claude to *attack* your ideas, plans, or writing rigorously.

- **Extended Thinking**: Enable Extended Thinking mode (brain icon or via prompt) for complex problems. Claude will reason step-by-step internally before answering.

- **Prompt Engineering Help**: When unsure how to prompt something well, ask Claude to write the perfect prompt for the task first.

## 4. Efficiency Tips (Save Tokens)

- **Specify output length** explicitly in your prompts (e.g. “Answer in maximum 300 words” or “Give me a concise bullet list”). This can reduce token usage dramatically.

- **Remove preamble** in Custom Instructions so Claude skips fluff like “Great question!”, restating the question, and long conclusions.

- **Don’t repeat context** every time — rely on Project + Custom Instructions.

- **Start a fresh chat** inside the Project for unrelated topics to avoid context pollution and extra tokens.

## 5. Ready-to-Use Prompts

The thread provides several powerful copy-paste prompts:

1. **Feynman-style explanation** (understand anything via analogies)
2. **Personalized travel planning** (based on how *you* actually travel)
3. **Monthly expense analysis** with real insights
4. **Personal thinking partner** for self-reflection
5. **Stress-test business ideas** (have Claude ruthlessly attack the idea)

(These specific prompts will be extremely valuable — they are tailored to get high-quality output immediately.)

## Final Takeaway

Claude isn’t necessarily smarter than you — but it has infinite patience, vast knowledge, and no ego. The people who get the most out of it treat it as a true collaborator by setting it up properly once (via Projects + rich context + custom instructions).
