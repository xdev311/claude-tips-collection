## Key Tools
- **Claude**: Script writing, ideas, niche research, titles, descriptions, etc.

## The System Breakdown

### Part 1: Niche Selection
Use Claude as market analyst. Focus on demand, views potential, RPM, competition, and production ease. Avoid picking niches just because you like them.

### Part 2: Script System
Strong scripts are critical. Claude can generate production-ready scripts with well-structured prompts.

### Part 3: Full Pipeline
Detailed step-by-step from idea → script → voiceover → editing → upload. Total time per video after setup: 45-90 minutes (mostly editing bottleneck).

### Part 4: Metadata Optimization
Titles, descriptions, tags are crucial for discoverability. Claude can generate optimized metadata.

### Part 5: Scaling to $5k–$10k+/month
- Weeks 1-4: Publish 3-4 videos/week, test formats
- Months 2-3: Double down on best-performing format
- Month 4+: Add monetization layers (affiliates, sponsorships, digital products)

### Part 6: 7 Mistakes to Avoid
1. Low RPM niche
2. Weak hook (first 30s)
3. Not posting enough (needs 20-30 videos for algorithm traction)
4. Direct copying
5. Using common free voices
6. Ignoring analytics
7. Moving too slowly

## Realistic Timeline
With full effort and consistency: possible to see significant results in 6 months.
