## Core Message
You do **not** need any coding knowledge to build real, useful AI agents. The only required skill is the ability to write **clear, detailed instructions in plain English**.

## Agent vs. Chatbot
- **Chatbot**: Reactive, single responses.
- **Agent**: Autonomous – given a goal, it plans, uses tools, iterates, and delivers complete results.

## Four Core Components
1. **Goal** – Clear and specific
2. **Plan** – Step-by-step
3. **Tools** – Web, files, calculations, etc.
4. **Loop** – Execute → check → adapt until done
